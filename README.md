# 港北区 保育園マップ

横浜市港北区の保育園 **132 園**を、**0歳児クラスの一次申請倍率**で
色分けして地図と一覧で見るためのページ。

**→ https://tomuso1992-rgb.github.io/hoikuen-map/**

個人が保活のために作ったもので、横浜市とは関係ありません。
数字は下記の出典から拾った参考値なので、申し込みの判断は
必ず市の公式資料と各園への確認で行ってください。

## できること

- **地図表示** — 倍率で 4 色に色分け。ドラッグで移動、ピンチ/ホイールで拡大縮小
- **起点からの距離** — 住所(町丁目)の入力・地図タップ・現在地のいずれかで
  起点を決めると、各園の徒歩・自転車の目安と 500m / 1km / 1.5km / 2km の距離円が出る
- **徒歩◯分以内でしぼる** — 5 / 10 / 15 / 20 分。一覧と地図の両方に効く
- **園の詳細** — 倍率・定員・職員数・駐車場・開園時間と、
  Googleマップ／ルート(徒歩・自転車)／えんさがしサポート／電話／公式サイトへのリンク
- **絞り込み** — 倍率帯、保育園/小規模、駐車場あり
- **並べ替え** — 倍率の低い順/高い順、起点から近い順、0歳児定員の多い順、
  申込者の少ない順、園名順
- **検索** — 園名・住所から
- **CSV書き出し** — いま表示している園だけを書き出す。Googleマイマップに読み込める

起点と設定はブラウザの `localStorage` にのみ保存され、どこにも送信されない。
このページにサーバーはなく、アクセス解析も入っていない。

## 表示の調整

一覧を広く使えるようにしてある。

- **絞り込みは折りたたみ式** — 初期状態では畳んであり、一覧が画面いっぱいに出る。
  「絞り込み・並べ替え・地図」のバーで開閉する。適用中の条件数がバッジに出る
- **一覧と地図の境界はドラッグで動かせる**(PC。320〜760px、ダブルクリックで既定値に戻る)
- **注意書きは常時表示しない** — 見出し右の **?** から全体の注意を、
  詳細パネル内の小さな **?** からその項目の注意を出す

幅と開閉状態はブラウザに記憶される。

## Googleマップ表示(任意)

左上の「地図」で **内蔵地図 / Googleマップ** を切り替えられる。
Googleマップ側は Maps JavaScript API を使うため **自分の APIキーが必要**。

キーは画面から入力し、`localStorage` にのみ保存される。
**このリポジトリにキーは含まれていないし、入力したキーが送信されることもない。**

Googleマップにすると、各園の位置が住所から取り直されて正確になり
(結果はキャッシュされるので照合は初回だけ)、
起点の欄にも番地まで入れられるようになる。

キーを作るときは **Maps JavaScript API** と **Geocoding API** の両方を有効にし、
キーの API 制限をその 2 つに絞ること。
このページのURLから使う場合は、HTTPリファラー制限を
`https://tomuso1992-rgb.github.io/hoikuen-map/*` にしておくと安全。

## データについて

| 項目 | 内容 |
| --- | --- |
| 倍率 | 一次申請時点の **申込数 ÷ 0歳児利用定員**。中央値 6.0 倍・最大 21.0 倍 |
| 位置 | 住所の**町丁目の代表点**。建物の正確な位置ではない |
| 距離 | 直線距離 × 道のり係数 1.3 を 徒歩 80m/分・自転車 250m/分で換算した概算 |
| 種別 | 総定員 19 名以下を小規模保育園と推定したもの。公式の区分ではない |

倍率は全体的に高いため、色分けは 3.0 / 6.0 / 9.0 倍を境にした 4 段階にしてある。

### 元データで欠けているところ

取り込み元の CSV には、そのまま使うと誤表示になる箇所がある。
`build/import_csv.py` が下記を検出して処理している。

- **保育・教育方針** … 全 132 行のうち実際の文章は 0 件で、94 行が
  スクレイピングで混入した `N /M 園内の様子`、38 行が空。カラムごと破棄し、
  以前のデータに実文があった 21 園ぶんだけ引き継いでいる
- **定員数** … 21 行で 0歳児利用定員と同じ値になっており、総定員が取れていない。
  そのまま使うと 60 名規模の園が「小規模保育園」になるため、**不明**として扱う
  (その園の種別は「不明」と表示される)
- **住所** … 1 園(すくすくの杜綱島SST保育園)は住所が空で、地図に出せない。
  一覧には出るが「住所の記載なし」と表示する

### 位置の精度

- 丁目まで特定できる住所(109 園) … おおむね 100〜300m の誤差
- 町までしか分からない住所(22 園) … 数百m の誤差

同じ町丁目の園は座標が完全に一致するため、代表点のまわりに
細い線でつないで扇状に並べている(位置は見た目上のもの)。
Googleマップ表示に切り替えて住所を照合すると、この誤差は解消する。

起点と園が 250m 以内のときは、両者の位置誤差より近いので分単位の目安は出さない。

## 作り直す

```
cd build
python3 import_csv.py <園一覧のCSV>   # 住所→町丁目の代表点、データの不備も処理
python3 build.py                      # template.html にデータを入れて index.html を書き出す
python3 make_csv.py                   # マイマップ用 CSV
```

`import_csv.py` は取り込みの結果(位置を特定できなかった園、総定員を不明にした件数、
精度の内訳、倍率の分布)を必ず表示する。園を足すだけなら
`build/nurseries_geo.json` を直して `build.py` を流すのが早い。

`build_geo.py` と `add_enmikke.py` は旧データからの移行に使ったもので、
いまは `import_csv.py` に統合されている。
